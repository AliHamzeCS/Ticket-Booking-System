# 🎟️ Ticket Booking System

A Python-based command-line Ticket Booking System.

This project is being developed as a learning project to practice Python programming concepts such as dictionaries, lists, loops, functions, modules, decorators, exception handling, and string methods.

## 🚀 Version

**Current Version: v0.1.0**

## ✨ Features

### 🎬 Movies

- Show all available movies
- Search for movies
- View movie details
- View movie schedules
- Filter movies by:
  - Genre
  - Rating
  - Price
  - Language

### 🖥️ Interface

- Colored command-line interface using Colorama
- Interactive menus
- Clear screen navigation
- Input validation
- Simple and organized menu structure

### 🧩 Python Concepts Used

- Variables
- Strings and String Methods
- Lists
- Dictionaries
- Sets
- Loops
- Conditional Statements
- Functions
- Modules
- `zip()`
- Decorators
- `try / except`
- Type Conversion
- Basic program organization
