# 🎟️ Ticket Booking System

A console-based Ticket Booking System built with Python.

This project is designed to practice Python programming concepts such as:
- Dictionaries
- Functions
- Loops
- Conditions
- Exception Handling
- Modules
- Random Number Generation
- Colorama
- Data management

---

## 🚀 Current Version

**v0.3.0**

---

## ✨ Features

### 🎬 Movies
- Show All Movies
- Search Movies
- Movie Details
- Show Movie Schedule
- Filter Movies
  - Filter by Genre
  - Filter by Rating
  - Filter by Price
  - Filter by Language

### 💺 Seats
- Show All Seats
- Show Available Seats
- Show Booked Seats
- Select Seat
- Check Seat
- Seat status is maintained separately for each movie and showtime

### 🎟️ Book Ticket
- New Booking
- Select Movie
- Select Showtime
- Select Seat
- Enter Customer Information
- Generate a unique Booking ID
- Display Booking Summary
- Confirm Booking
- Update selected seat to `Booked` after confirmation
